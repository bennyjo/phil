## Strategy edit

The revision rule exists, but it only adjusts the probability. This
week shows the preliminary count also anchors the book, so an edge
built on it is mostly fake. Added to the playbook USGS ruling: **a
USGS count or daily-max BET requires that the edge survives on the
count of `mww` (or `reviewed`) events alone.** Preliminary `mb`/`ml`
events within 0.3 of the threshold may move a forecast (with the 0.20
revision weight), never create a bet's edge. Evidence: d5cfa982fa21
(Banda Aceh revised 5.5+ to 5.3), 4ea5508aaf4c (Volcano Is. 5.5 to
5.1), dc9200183ac0 (count 7 to 5). n=3 revisions, all downward.
